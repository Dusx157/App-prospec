# Set Intermediate Waypoints Along a Route

This sub-workflow guides you through configuring intermediate waypoints between
an origin and a destination using the Routes API (`computeRoutes` method).

## Prerequisites

-   **Routing Request Setup**: Ensure you have a base routing request configured
    (e.g., `computeRoutes` endpoint, authentication headers, `origin`, and
    `destination`).

## Overview & Key Concepts

Intermediate waypoints are locations specified between the origin and
destination that you want the route to go through. You can define up to **25
intermediate waypoints** in a single request using the `intermediates` array
property.

> **Billing Caution:** Requests containing between 11 and 25 intermediate
> waypoints are billed at a higher rate than requests with 1 to 10 intermediate
> waypoints.

### Stopovers vs. Pass-through Waypoints

When defining an entry in the `intermediates` array, you must decide how the
vehicle interacts with the location:

1.  **Stopover (Default)**:

    -   The vehicle stops at the location (`"via"` is omitted or set to
        `false`).
    -   Divides the route into separate segments by adding a `RouteLeg` entry to
        the `routes.legs` array in the response.
    -   *Example*: A route with an origin, 1 intermediate stopover, and a
        destination returns **2 route legs** (Leg 1: Origin to Stopover; Leg 2:
        Stopover to Destination).

2.  **Pass-through Waypoint**:

    -   Set `"via": true` inside the waypoint object.
    -   The route passes through the location without stopping.
    -   Does **not** add new entries to the `routes.legs` array.

--------------------------------------------------------------------------------

## Implementation Workflow

### 1. Define the `intermediates` Array

Add the `intermediates` array to your `computeRoutes` request payload. Each
element in the array is a
[Waypoint](https://developers.google.com/maps/documentation/routes/reference/rest/v2/Waypoint)
object (specified via `location` coordinates, `placeId`, or `address`).

### 2. Update the Field Mask

To inspect the individual route legs generated by stopover waypoints, ensure you
include `routes.legs` in your `X-Goog-FieldMask` header.

### 3. Execute the Request

Below is a complete REST example demonstrating a route with one intermediate
stopover waypoint.

```bash
curl -X POST -d '{
  "origin":{
    "location":{
      "latLng":{
        "latitude": 37.419734,
        "longitude": -122.0827784
      }
    }
  },
  "destination":{
    "location":{
      "latLng":{
        "latitude": 37.417670,
        "longitude": -122.079595
      }
    }
  },
  "intermediates": [
    {
      "location":{
        "latLng":{
          "latitude": 37.419734,
          "longitude": -122.0807784
        }
      }
    }
  ],
  "travelMode": "DRIVE"
}' \
-H 'Content-Type: application/json' \
-H 'X-Goog-Api-Key: YOUR_API_KEY' \
-H 'X-Goog-FieldMask: routes.duration,routes.distanceMeters,routes.legs' \
-H 'X-Goog-Maps-Solution-ID: gmp_git_agentskills_v1' \
'https://routes.googleapis.com/directions/v2:computeRoutes'
```

## Expected Response Structure

Because the intermediate waypoint in the example above is a default stopover (it
does not set `"via": true`), the response divides the route into two distinct
legs inside the `legs` array:

```json
{
  "routes": [
    {
      "distanceMeters": 805,
      "duration": "248s",
      "legs": [
        {
          "distanceMeters": 207,
          "duration": "89s",
          "startLocation": {
            "latLng": {
              "latitude": 37.4197318,
              "longitude": -122.0826233
            }
          },
          "endLocation": {
            "latLng": {
              "latitude": 37.419734,
              "longitude": -122.0807792
            }
          }
        },
        {
          "distanceMeters": 598,
          "duration": "159s",
          "startLocation": {
            "latLng": {
              "latitude": 37.419734,
              "longitude": -122.0807792
            }
          },
          "endLocation": {
            "latLng": {
              "latitude": 37.4176166,
              "longitude": -122.0793882
            }
          }
        }
      ]
    }
  ]
}
```
